# Code Alongs

This repo contains the finished code from our LaunchCode code-along sessions. Use it to review what we built, follow along with a recording, or try the projects on your own.

## Projects

### Mini Shop

We built a storefront landing page with React and Vite.

#### Run Mini Shop locally

Clone or download this repo. With Node.js and npm installed, open the folder containing Mini Shop's `package.json` in your terminal and run these commands.

```sh
npm install
npm run dev
```

Open the local URL shown in your terminal.

If PowerShell blocks `npm`, use `npm.cmd install` and `npm.cmd run dev`.
